# CaptureTheFlag

Lka09의 CTF(Capture The Flag) 문제 풀이 및 학습 내용을 기록하는 레포지토리입니다.

CTF 문제를 해결하는 과정에서 사용한 분석 방법, 취약점 및 풀이 과정을 정리합니다.

---

## 📁 레포지토리 사용 방법

1. **문제 파일 업로드**
   - CTF 문제에서 제공된 파일을 업로드합니다.

2. **Write-up 작성**
   - 문제의 핵심 원리와 취약점을 분석합니다.
   - 문제 해결 과정과 사용한 기법을 정리합니다.
   - 최종 풀이 과정과 결과를 기록합니다.

3. **풀이 스크립트 첨부**
   - Python 등을 활용해 작성한 풀이 스크립트를 함께 업로드합니다.
   - HTTP 요청 자동화, 복호화, 익스플로잇 등에 사용한 코드도 포함합니다.

## 🎯 목적

CTF 문제 풀이 과정을 체계적으로 기록하고, 분석 능력과 보안 지식을 향상시키는 것을 목표로 합니다.
